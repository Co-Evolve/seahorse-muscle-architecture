# Tendon Designer: design notes and contracts

A browser app in which a (non-programmer) student defines tendon configurations on
the seahorse tail model by clicking on per-segment slice views, simulates them live
with MuJoCo WebAssembly, measures bending, and compares configurations.

Everything runs locally: `python -m seahorse_muscle_architecture.silico.tendon_designer.serve`
starts a static HTTP server on `web/` and opens the browser.

need it), never opened as `file://`.

## Model facts (11-segment default morphology)

* Segment `i` = body `segment_{i}`; its moving frame is body `segment_{i}_vertebrae`
  ("segment frame"). Segment 0 is welded to the world. Segment spacing 0.032 m along +z.
* Segment frame axes: **+x = ventral**, −x = dorsal, **+y = sinistral**, **−y = dextral**, +z = towards tail tip.
  (Verified from the vertebra strut sites and the HM plate corners. NB: the body named
  `..._connector_dextral_body` sits at +y; ignore that name.)
* Each segment has 4 plates (`segment_{i}_plate_{p}`, children of the segment frame,
  rest pose = identity). Plate index → corner: 0 `ventral_dextral`, 1 `ventral_sinistral`,
  2 `dorsal_sinistral`, 3 `dorsal_dextral`. Plates glide in x/y (slide joints
  `segment_{i}_plate_{p}_{x|y}_axis`), coupled to neighbouring segments by equality constraints.
* Vertebral joints (segments 1..n-1): `segment_{i}_vertebrae_vertebrae_joint_{pitch|roll|yaw}` (hinges).
  pitch = about y (ventral/dorsal flexion), roll = about x (lateral bending), yaw = about z (axial twist).
* Passive vertebral struts: spatial tendons `segment_{i}_vertebral_vertebral_strut_{ventral|sinistral|dorsal|dextral}`.
* Tendon "holes" in plates are modelled as a pair of sites (proximal face, distal face).
* `compiler angle="radian"`. Contacts disabled. Gravity disabled in the base model.

                 "roll_stiffness": .., "roll_damping": .., "roll_range_deg": ..,

      "vertebra_outline": [[[x,y], ...], ...],   // polygons, segment frame, metres
      "plates": [
        {
          "index": 0, "corner": "ventral_dextral",
          "body": "segment_0_plate_0",           // body that free-point sites are added to
          "outline": [[[x,y], ...], ...],        // silhouette polygons (projection on xy), segment frame
          "free_site_z": [z_proximal, z_distal], // local z (in `body` frame) for the two sites of a free point
          "taps": [
            {
              "id": "segment_0_plate_0_intermediate_hm_tap_3",
              "kind": "intermediate" | "ghost" | "end" | "mvm",

Plate bodies have identity rest pose in the segment frame, so a free point at segment-frame
`(x, y)` gets sites at local `pos = (x, y, free_site_z[k])` in `body`.

## Configuration JSON (the student's file)

```jsonc
{
  "format": "seahorse-tendon-config", "version": 1,
  "name": "HM fork 5→9 + 10",
  "description": "free text",
  "params": { ... },            // optional overrides, see below; missing/null = base value
  "free_points": [
    {"id": "free_1", "segment": 8, "plate": 0, "xy": [0.031, -0.02]}
  ],
  "tendons": [
    {
      "name": "hm_dextral",                 // [A-Za-z0-9_-]+, unique, must not start with "segment_"
      "group": "dextral",                   // free label; comparisons drive tendons by group
      "color": "#3b82f6",
      "width": 0.001,
      "damping": 0.01,                      // tendon damping
      "stiffness": 0.0,                     // passive tendon stiffness (N/m); springlength = rest length
      "actuator": {"type": "motor", "max_force": 10}
               // | {"type": "position", "kp": 1000, "max_force": 1000, "max_strain": 0.26}
               // | {"type": "none"}        (purely passive tendon)
      "path": ["<point id>", ...],          // trunk: start -> ... -> first distal end (>= 2 points)
      "branches": [
        {"from": 3, "path": ["<point id>", ...]}   // split at trunk point index 3, continue through path (>= 1 point)
      ]
    }
  ]
}
```

A point id is a catalog tap `id` or a `free_points[].id`.

### Site expansion rules (JS and Python MUST implement identically)

1. `S(P)` = ordered site list of point `P` (catalog `sites`, or `[id+"_0", id+"_1"]` for free points).
   `seg(P)` = its segment index.
2. Trunk direction `D = sign(seg(last) - seg(first))`, or `+1` if 0. Each trunk point contributes
   `S(P)` if `D > 0`, else `reverse(S(P))`.
3. Branch `{from: k, path: [Q1..Qm]}`: direction `Db = sign(seg(Qm) - seg(P_k))` or `+1` if 0.
   Emit `<pulley divisor="1"/>`, then the **exit site** of `P_k` (last element of `S(P_k)` ordered by `Db`),
   then `S(Qj)` ordered by `Db` for every `Qj`.
4. Drop a site if it equals the immediately preceding emitted site (same branch).
5. Branches start from trunk points only (v1).

### Generated MJCF per tendon (name `N`)

```xml
<spatial name="N" width=".." rgba=".." damping=".." stiffness=".." springlength="-1 -1"> ...sites/pulleys... </spatial>
<!-- motor -->    <motor name="N" tendon="N" gear="F" ctrllimited="true" ctrlrange="-1 0" forcelimited="true" forcerange="-F 0"/>
<!-- position --> <position name="N" tendon="N" kp="KP" ctrllimited="false" forcelimited="true" forcerange="-F 0"/>
<sensor> <tendonpos name="N_length" tendon="N"/> <actuatorfrc name="N_force" actuator="N"/> (if actuated) </sensor>
```

Activation `a ∈ [0, 1]` → `ctrl`: motor `ctrl = -a`; position `ctrl = length0 * (1 - a * max_strain)`
(`length0` = tendon length at qpos0, `model.tendon_length0`).

### `params` overrides

```jsonc
{
  "vertebra": {"pitch_stiffness", "pitch_damping", "pitch_range_deg",
               "roll_stiffness",  "roll_damping",  "roll_range_deg",
               "yaw_stiffness",   "yaw_damping",   "yaw_range_deg"},
  "stiffness_taper": 1.0,     // vertebra stiffness multiplier, linear from 1.0 at segment 1 to this at the last segment
  "plate_glide": {"stiffness", "damping"},
  "strut": {"stiffness", "damping"},
  "orientation": "upright" | "hanging",   // hanging: segment_0 euler="3.141592653589793 0 0" (tail along -z)
  "gravity": true | false,
  "timestep": 0.002
}
```

Applied as explicit attributes on the matching elements (ranges symmetric: `range="-r r"` in radians).

## JS module contracts

```js
// model_builder.js
export function expandTendonSites(tendon, catalog, freePoints) // -> array of {site: name} | {pulley: 1}
export function buildModelXml(baseXml, catalog, config)        // -> MJCF string (uses DOMParser/XMLSerializer)

// sim.js
export async function loadMujoco()                 // singleton MuJoCo WASM module
export async function loadAssets(baseUrl = "model/") // -> {baseXml, catalog, meshes: {fileName: Uint8Array}}
export class Simulation {
  static async create(mujoco, assets, config)      // build XML, write VFS, compile; throws Error with readable message
  xml; model; data; config; catalog;
  tendons                                          // [{name, group, color, type, tendonId, actuatorId|null, length0}]
  time                                             // simulated seconds
  setActivation(name, a) / getActivation(name) / setActivations({name: a})
  step(n = 1)                                      // n mj_step calls
  advance(seconds)                                 // steps to cover `seconds` of sim time
  reset()                                          // qpos0, zero activations kept? -> activations kept, state reset
  measure()                                        // -> Measurement (below)
  dispose()
}

// render3d.js
export class Viewer3D {
  constructor(container, options)                  // options: {background, showSites, showStruts, plateOpacity}
  setSimulation(sim)                               // (re)build scene from sim.model
  update()                                         // sync with sim.data (call every frame)
  setTendonHighlight(name | null)
  setOptions(partialOptions)
  resize(); dispose()
}

// slice_editor.js
export class SliceEditor {
  constructor(container, catalog, {onChange, onSelectTendon})
  setConfig(config)                                // editor works on a deep copy; onChange(newConfig) on every edit
  setActiveTendon(name)
  setSegment(index)
}
```

### Measurement (returned by `Simulation.measure()`)

Angles in degrees. For frames A (parent) and B, with B's z-axis expressed in A: `v = R_A^T z_B`:
`ventral = atan2(v.x, v.z)` (+ = towards ventral), `lateral = atan2(-v.y, hypot(v.x, v.z))` (+ = towards dextral, i.e. −y; = asin(−v.y), stable beyond 90° of ventral bend),
`bend = acos(v.z)`; `twist` = rotation of B's x-axis about B's z relative to A (signed).

```jsonc
{
  "time": 1.23,
  "tip": {"pos": [x,y,z], "displacement": [dx,dy,dz], "distance": d,   // tip = last segment frame origin, base frame = segment_0_vertebrae
          "ventral": .., "lateral": .., "bend": .., "twist": ..},       // tip frame relative to base frame
  "segments": [{"index": i, "pos": [..], "ventral": .., "lateral": .., "bend": .., "twist": ..,     // i=1..n-1, relative to segment i-1
                "joint_angle": {"pitch": .., "roll": .., "yaw": ..},        // deg, qpos of the vertebral hinges
                "torque": {"pitch": .., "roll": .., "yaw": ..},             // N·m applied by ALL tendon actuators on this vertebral joint (qfrc_actuator at its dof)
                "passive_torque": {"pitch": .., "roll": .., "yaw": ..},     // N·m from joint springs/dampers + passive tendons/struts (qfrc_passive)
                "limit_torque": {"pitch": .., "roll": .., "yaw": ..}}],     // N·m from joint-range limits (qfrc_constraint at that dof; equality-constraint parts included)
  "cumulative_ventral": [..],          // running sum of segment ventral angles (index 0 = 0)
  "tendons": [{"name", "group", "activation", "length", "length0", "excursion",   // excursion = length0 - length (shortening > 0)
               "strain",               // excursion / length0
               "force",                // pulling force in N (>= 0), 0 if passive & slack
               "work",                 // J, integrated force * shortening velocity since reset
               "moment_arms": [{"segment": i, "pitch": .., "roll": .., "yaw": ..}],   // m, d(length)/d(joint angle) for each vertebral joint (row of the tendon Jacobian ten_J)
               "torque": [{"segment": i, "pitch": .., "roll": .., "yaw": ..}]}],      // N·m this tendon alone applies = -moment_arm * force (sign so that it matches qfrc_actuator)
  "energy": {"elastic": ..}            // optional
}
```

### Vertebral torques (requested by the PI)

The student must be able to extract the vertebral torques that result from a contraction:
live per-joint torque readout + plot (torque vs segment, per joint axis; per-tendon contribution
stacked), torque time series, and torques in every CSV export. Reference: the paper's
`contraction_force_to_torque` experiment reads `jointactuatorfrc` sensors on the vertebral
joints, which equals `qfrc_actuator` at that dof. Units shown to the student: N·mm.
